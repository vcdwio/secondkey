# Data Dictionary

All people, organisations, events and records are fictional. Email addresses use the reserved .example domain.

## Core identifiers

- VC-* — Verge Consulting staff
- CL-* — Client account
- CT-* — Client contact
- PJ-* — Project
- EM-* — Email
- MT-* — Meeting
- CALL-* — Call log
- TK-* — Ticket or request
- EV-* — Calendar event
- EVL-* — Evaluation scenario

## Required controls

- mode is demo.
- external_write must remain false.
- Client access groups must be preserved during retrieval.
- Archived knowledge cannot override active policy.
- A proposed action is not an executed action.
